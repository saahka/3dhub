# 3DHub Code Assets — текстурированная версия
https://saahka.github.io/3dhub/
Каталог из 35 Three.js-моделей с готовым JavaScript-кодом: выбери объект, посмотри его в 3D и скопируй функцию в свою HTML-игру.

## Использование

1. Откройте сайт (см. GitHub Pages ниже) в современном браузере.
2. Выберите модель → «Копировать код» → вставьте функцию в JavaScript своей HTML-игры, где уже подключён Three.js.
3. Добавьте объект в сцену: `scene.add(createChair());`

## Особенности

- Геометрия собирается из Three.js-примитивов, каждой модели добавлены индивидуальные детали.
- Материалы получают встроенную CanvasTexture — текстура генерируется кодом, отдельные файлы изображений не нужны.
- Экспортируемый код не зависит от этого сайта после копирования; нужен только Three.js.
- Для предпросмотра на сайте требуется доступ к CDN jsdelivr.net (откуда загружается Three.js).

## Публикация через GitHub Pages

1. Settings → Pages.
2. Build and deployment: Deploy from a branch, ветка `main`, папка `/(root)`.
3. После публикации GitHub покажет адрес сайта.
